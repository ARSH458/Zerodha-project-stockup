StockUp – Stock Trading Learning Platform

StockUp is a MERN stack-based stock trading learning platform inspired by Zerodha. The project is designed for
educational purposes to help users understand portfolio management, holdings, positions, dashboard analytics,
backend APIs, and full-stack application architecture without using real money.


Key Features
• User Authentication and Login System
• Dashboard Interface with Portfolio Insights
• Holdings and Positions Management
• REST API Integration
• MongoDB Database Connectivity
• Backend Testing using Jest
• Responsive Full-Stack Architecture


Technology Stack
Frontend: React.js, HTML, CSS, JavaScript, Bootstrap, Material UI
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT Authentication
Testing: Jest
Deployment: AWS (Planned) 

Learning Outcomes
This project helped in understanding MERN stack architecture, REST API development, frontend-backend integration,
MongoDB database management, authentication systems, and software testing workflows.
