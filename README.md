# StockUp – Stock Trading Learning Platform

StockUp is a MERN stack-based stock trading learning platform inspired by Zerodha.

The project is designed for educational purposes to help users understand:
- Portfolio management
- Holdings and positions
- Dashboard analytics
- Backend APIs
- Full-stack application architecture

without using real money.

---

# Key Features

- User Authentication and Login System
- Dashboard Interface with Portfolio Insights
- Holdings and Positions Management
- REST API Integration
- MongoDB Database Connectivity
- Backend Testing using Jest
- Responsive Full-Stack Architecture
